# School Diary Full-Stack Runbook

For the full installation guide, database architecture, API list, imports, account setup, security notes, and backup/recovery steps, read [`README.md`](README.md), [`docs/DATABASE_ARCHITECTURE.md`](docs/DATABASE_ARCHITECTURE.md), [`docs/API_REFERENCE.md`](docs/API_REFERENCE.md), and [`docs/OPERATIONS_AND_SECURITY.md`](docs/OPERATIONS_AND_SECURITY.md).

Windows quick start: extract the project, run `START-FULL-STACK.bat`, wait for Docker Compose to build/start the services, then browse to `http://localhost:3001`. First-run accounts are in `README.md`; change temporary passwords immediately.
