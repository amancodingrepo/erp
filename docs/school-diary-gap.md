# School Diary spec vs this ERP

Source: `docs/school-diary-erp-spec/` (independent rebuild notes). Do not copy vendor UI, logos, or source.

Campus in this product = spec **Branch**. Academic session = spec **Academic year**.

## In this ERP now

| Spec area | Status |
| --- | --- |
| Auth, campus tenancy, staff/student/parent portals | Present (JWT + campus code, not membership-switch table) |
| Classes, enrollments, roll numbers, bulk CSV | Present |
| Students + guardians + documents | Present (nested guardians + document DELETE) |
| Fee types, masters, collect, ledger, reminders | Present (installment grid on student profile) |
| Attendance books | Present (student/staff) |
| Notices + read receipts | Present (nested virtual channels school/teachers/daycare/class:{id}/route:{id}; receipts + not-viewed) |
| Parent Requests inbox/sent/scheduled/unseen | Present (reply/reopen + extra filters in this pass) |
| Daycare flag, in/out transport, immunization | Present |
| Online apply, Hindi toggle, multi-campus admin | Present |
| Library, thin store/payroll, exams, reports runner | Thin / partial (must-have keys: strength, dues, daily attendance, notice views) |

## Landed in this pass

- Houses master
- Notice **channel** (school / teachers / daycare / class / route) + **type** (news / alert / homework) + allow reply + **not viewed**
- Campus **events** calendar
- Request **reply / reopen** and name/date filters
- Daycare **check-in / check-out** timestamps
- Must-have reports on the existing runner: **strength**, **daily-attendance**, **notice-views** (fee due already `dues`). Counts come from live enrollments / attendance / notice reads — no hardcoded class or status catalog.
- Contacts directory (audiences from live classes), search users (phone/email/school ids → fees tab), attendance dashboard KPIs (status buckets from marks), daycare roster

- Promote desk procedures: promote, same-year change class, alumni (`StudentStatus.ALUMNI`).
- Houses master plus bulk change house (`POST /api/v1/houses/assign`, campus-scoped house id).
- Attendance **Not Taken** is a missing mark (not PRESENT). Daily KPIs use enrolled current students vs daily (`subjectId` empty) marks. Status options come from the Prisma attendance enum on the roster.
- Fee master template: live fee-type rows grouped by due date into one master per installment, then assign to class as before.
